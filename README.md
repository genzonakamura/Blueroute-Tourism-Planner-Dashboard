# Blueroute-Tourism-Planner-Dashboard
Terengganu EcoTourism Dashboard merupakan sebuah aplikasi analitik interaktif yang dibangunkan menggunakan Streamlit dan Plotly untuk menyokong perancangan pelancongan mampan di negeri Terengganu. Projek ini direka khas untuk menangani isu isu kesesakan lalu lintas, pemantauan kapasiti di zon pelancongan popular
